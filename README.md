# 🐟 故鄉魚塭

一公頃的 3D 混養魚塭 PWA，用 three.js 製作，可加到手機主畫面、離線使用。

**線上版：** https://kftseng2oo1.github.io/fish-pond/

## 功能

- **魚塭**：100 m × 100 m＝1 公頃，水深約 1.6 m，土堤、工寮、電線桿、外海水道與沙灘
- **混養**：虱目魚成群洄游、草蝦在池底爬行彈跳、文蛤半埋底泥冒泡；可在「放養數量」自由增減，放越多溶氧越低
- **水車**：四台葉輪增氧機打水、帶動整池環流，關掉後溶氧會慢慢下降，太低時魚群浮頭
- **鹽度**：海水閘門引海水、淡水抽水站注淡水，左上角即時顯示鹽度與溶氧，池水顏色隨鹽度變化
- **竹筏餵料**：三位養殖戶可選（阿雄伯、阿蘭姨、阿明）；飼料一袋一袋分虱目魚浮性料、草蝦沉性料，撒料時虱目魚會躍出水面搶食
- **濕地鳥類**：黑面琵鷺、埃及聖䴉、高蹺鴴、東方環頸鴴、蒼鷺、翠鳥、小白鷺，會覓食、飛行、受驚飛走，翠鳥會俯衝入水抓魚
- **四角監視器**：可轉動、拉近 15 倍、四分割、自動巡航、夜間紅外線；畫面中的鳥會被自動辨識框起來（可關閉），點框或「找牠」就會追蹤，並記錄觀鳥紀錄
- **魚網收成**：冷藏貨車倒車進場、工人兩岸牽網把魚蝦趕到池邊、收成網袋、撈網撈進籃子、扛上貨車載走，最後可以放魚苗重新養
- **日夜切換**：星空、月亮、堤岸路燈；夜裡草蝦活躍、溶氧下降
- **互動**：點水面起漣漪嚇魚、點魚或鳥跟拍、地點標籤
- **拍照**：含浮水印（時間、鹽度、溶氧、監視器編號），可分享或下載
- **環境音效**：水車、海浪、閘門進水、鳥叫、蟲鳴蛙叫、倒車聲，全部由程式即時產生
- **螢幕保護模式**：隱藏介面、自動運鏡並輪流跟拍，防止螢幕休眠；網址加 `?kiosk=1` 開啟就直接進入
- **畫質**：高畫質（陰影、高解析）與省電畫質，裝置吃力時自動降級
- **混養須知**：分層分工、鹽度、溶氧與水車、投餵、日常巡池

## 網址參數

| 參數 | 說明 |
|---|---|
| `?kiosk=1` | 直接進入螢幕保護模式（適合電視、平板當擺設） |

| 檔案 | 說明 |
|---|---|
| `index.html` | 主程式 |
| `manifest.json` | PWA 設定 |

| `three.min.js` | three.js r128 |
